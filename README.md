# poc-vaultwarden
Proof of concept for [Self-Hosting Vaultwarden: Replace LastPass with Your Own Password Manager](https://www.ardotconsulting.com/blog/2026/10/16/self-hosting-vaultwarden-replace-lastpass-with-your-own-password-manager/)

Locked down: signups disabled, admin panel protected by `ADMIN_TOKEN` (generated secret). Ryan creates the demo account from `/admin`.
